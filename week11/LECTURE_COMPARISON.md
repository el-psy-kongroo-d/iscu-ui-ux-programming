# week11: 공개 강의 원본과 데브플랜 변경

## 원본

- 저장소: [boracles/uiuxprogramming](https://github.com/boracles/uiuxprogramming)
- 원본 커밋: [`f71945af2d24b70613eefd0df4370857c154136c`](https://github.com/boracles/uiuxprogramming/commit/f71945af2d24b70613eefd0df4370857c154136c)
- 추출 파일: `index.html`, `style.css`, `script.js`; 강의 이미지는 서비스 목적과 무관해 복사하지 않았습니다.

- 공개 원본 커밋 메시지는 “11주차, 유닛1”입니다. 이 커밋이 11주 전체 영상의 최종본인지는 확인할 수 없습니다. 이 디렉터리는 지정 커밋 파일을 기반으로 구현하고 아래의 별도 보완을 적용했으며, 이후 차시 기능을 가정하지 않습니다.
- Re:hear 워드마크 대신 텍스트 “데브플랜”을 사용했습니다. 발표 장면 히어로 이미지는 개발 학습 서비스와 맞지 않아 제거했습니다. 따라서 이 원본의 이미지 대체 텍스트 사례도 최종 페이지에는 남아 있지 않습니다. 학습 코드 이미지 등 대응 자산은 추가하지 않았습니다.
- 발표 정보는 개발 학습 주제와 선택 입력 학습자 이름으로, 발표/훈련은 학습으로 바꾸었습니다.
- 선택 시간은 3·5·10분에서 15·30·60분으로, 질의응답 설정은 복습 문제 수 1·2·3개로 바꾸었습니다. 주제 입력 조건 2~60자는 9주차 강의 원본을 따릅니다. 기존 midterm의 100자 상한과 다릅니다.
- 명시적 대화상자 닫기 버튼, 저장·취소 상태 강조, 현재 내비게이션 위치에 따른 `document.title` 갱신을 유지했습니다. 저장은 `devplan-week11-plans-v1` 키를 사용합니다.
- 의미 없는 발표 이미지용 CSS를 제거하고 hero를 한 열로 조정했습니다.
- 제목 2~60자 제한을 검증하고, 완료 뒤 계획 링크를 새 계획으로 연결했습니다. 저장 성공 시 저장됨 필터와 상태 표시를 맞추고, 필터링으로 카드가 사라지면 선택 필터로 초점을 옮깁니다. 메뉴 링크는 목적지 제목으로 초점을 보내며, 다크 모드 저장됨 필터의 글자 대비도 보완했습니다.

- 원본의 저장 중 상태에서는 확인 단계 수정 버튼이 계속 활성화되어 입력을 바꿀 수 있었습니다. 저장 중 두 수정 버튼을 비활성화하고 성공·오류 후 다시 활성화하도록 보완했습니다.

## 확인 범위와 미확인 사항

- 과제 상세 지시문(LMS)과 공개 강의 영상을 직접 대조하지 않았습니다. LMS 세부 조건이나 영상의 화면·설명과 일치하는지는 미확인입니다.
- 이 페이지는 학습 계획의 입력·선택·저장·조회 프로토타입입니다. 서버 계정, 학습 이행 측정, 문제 생성은 구현하지 않았습니다.
- 로컬에서 실행 가능한 동작 검사 페이지는 포함하지만, 본 기록 시점에 브라우저 자동 실행은 수행하지 않았습니다. 배포 상태도 확인하지 않았습니다.
- `tests.html`에는 제목 상한, 진행 중 입력 보존, 완료 후 새 계획 시작, 메뉴 초점 복귀, 필터·초점 회귀 검사를 포함했습니다.

추출한 HTML·CSS·JavaScript의 줄 끝 공백을 정리했습니다. 기능 동작은 바꾸지 않았습니다.
