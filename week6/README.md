# 6주차 과제: 데브리허설 이벤트 처리와 동적 UI 구현

프로젝트 발표와 기술 면접을 준비하는 개발자를 위한 ‘데브리허설’입니다. 맡은 역할과 기술 선택 이유를 자신의 말로 설명하는 연습을 주제로 정했습니다. 5주차의 이메일 신청 기능을 이어받고, 6주차의 이벤트 처리와 화면 상태 전환을 적용했습니다.

## 구현 내용

- 라이트·다크 테마 전환
- 발표자 이름 입력에 따른 글자 수 표시
- 녹음 활용 동의 여부에 따른 시작 버튼 활성화
- 프로젝트 소개·기술 질문·설명 점검 탭 전환

## 파일 구성

- `index.html`: 서비스 소개와 발표 준비 설정 화면
- `style.css`: 레이아웃, 테마, 탭 상태와 반응형 스타일
- `script.js`: 이메일 신청, 입력·동의 이벤트와 탭 전환

## 실행

[배포 페이지](https://el-psy-kongroo-d.github.io/iscu-ui-ux-programming/week6/)에서 확인할 수 있습니다. 로컬에서는 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000/week6/`를 엽니다.

## 참고

5주차 피드백에 따라 수업 예제의 서비스명과 소개·안내 문구를 기획 주제에 맞게 수정했습니다. 코드 구조·줄 배치·이벤트 처리·CSS는 유지했으며, 이제 HTML·JavaScript 전체가 강의 원본과 바이트 단위로 같지는 않습니다. [대조 기록](LECTURE_COMPARISON.md)에 원본 확인 근거와 개인화 범위를 정리했습니다. 소개 이미지는 수업 예제의 가상 청중 이미지를 재사용했습니다. 모바일 체크박스 배치 문제도 원본 그대로입니다.

이메일 신청과 녹음 동의는 화면 시연이며 실제 전송·녹음·저장은 하지 않습니다.
