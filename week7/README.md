# 7주차 과제: 데브리허설 사용자 흐름과 인터랙션 구현

6주차의 개발자 발표 연습 서비스 ‘데브리허설’에 단계별 설정 흐름을 적용했습니다. 소개할 프로젝트의 발표 제목과 시간을 정하고, 기술 질의응답을 포함할지 선택합니다.

## 구현 내용

- 녹음 활용 안내 팝업과 취소·Escape에 따른 동의 해제
- 발표 제목 입력과 빈 값 검증
- 발표 시간 3·5·10분 선택
- 질문 포함 여부와 질문 수 1·2·3개 선택
- 설정 요약 확인과 완료 화면
- 이전 단계의 입력 유지와 다시 설정 시 초기화

## 파일 구성

- `index.html`: 안내 팝업과 정보·조건·확인·완료 화면
- `style.css`: 팝업, 단계 표시, 입력 오류와 반응형 스타일
- `script.js`: 입력 검증, 조건 분기, 단계 이동과 초기화

## 실행

[배포 페이지](https://el-psy-kongroo-d.github.io/iscu-ui-ux-programming/week7/)에서 확인할 수 있습니다. 로컬에서는 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000/week7/`를 엽니다.

## 참고

5주차 피드백에 따라 서비스명·소개·예시·안내 문구를 개발자의 프로젝트 발표와 기술 질의응답에 맞췄습니다. 강의의 코드 구조·줄 배치·이벤트 처리와 CSS는 유지했습니다. 문구가 달라 HTML·JavaScript 전체의 바이트 일치를 주장하지 않습니다. 영상에서 잘린 JavaScript 줄 끝의 동일성도 미확인입니다. [대조 기록](LECTURE_COMPARISON.md)에 확인 범위와 개인화 내역을 정리했습니다. 소개 이미지는 수업 예제를 재사용했고, 모바일 체크박스 배치 문제는 원본 그대로입니다.

실제 전송·녹음·저장·AI 분석 없이 화면 흐름만 시연합니다.
