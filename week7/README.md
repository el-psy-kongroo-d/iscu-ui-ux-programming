# 7주차 과제 · 사용자 흐름과 인터랙션 시나리오 구현

## 사용자와 서비스

발표를 앞둔 학습자가 Re:hear에서 오늘의 연습 계획을 정하는 상황을 가정했다. 목적은 연습 주제와 목표를 정하고, 사용할 수 있는 시간에 맞춰 준비를 끝내는 것이다. 핵심 행동은 연습 계획 확인이며, 완료 조건은 주제·난이도·목표·시간이 확인 화면에 반영된 뒤 준비 완료 화면에 도달하는 것이다.

6주차의 서비스 소개, 기능 소개, 탭 3개, 검색·난이도 필터, 카드 선택, 알림 입력 확인 기능을 유지했다. 연습 카드를 누르면 같은 주제가 준비 화면에 선택된다. 이 과제는 화면 상태를 연결한 프로토타입이며 실제 녹음·AI 분석·서버 저장은 구현하지 않았다.

## 핵심 흐름

1. 발표 주제를 선택한다.
2. 난이도와 오늘의 목표, 연습 시간을 입력한다.
3. 확인 화면에서 계획을 검토하고 팝업에서 계획을 확정한다.
4. 완료 화면에서 계획과 다음 행동을 확인한다.

필수값이 없으면 다음 단계로 이동할 수 없고, 오류 원인을 안내한다. 이전 단계로 돌아가도 선택값과 입력값을 유지한다. 완료 후에는 `처음부터 다시 시작` 버튼으로 흐름 상태를 초기화한다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 연습 카드 선택 | click | 카드의 주제 있음 | 해당 주제 선택, 준비 영역으로 초점 이동 | 주제 선택 |
| 목표와 시간 정하기 | click | 주제 미선택 | 수정 안내와 첫 선택 버튼으로 초점 이동 | 현재 단계 유지 |
| 목표와 시간 정하기 | click | 주제 선택됨 | 조건 입력 화면 표시 | 내용 입력 |
| 연습 계획 확인 | click | 난이도·목표·시간 중 누락, 공백 목표 포함 | 누락한 항목 안내, 오류 속성과 초점 표시 | 현재 단계 유지 |
| 연습 계획 확인 | click | 필수값 있음 | 주제·난이도·목표·시간 표시 | 확인 |
| 주제 다시 선택·내용 수정 | click | 이전 화면으로 이동 | 입력·선택값 유지, 수정 후 확인에 재반영 | 주제 선택·내용 입력 |
| 이 계획으로 준비 완료 | click | 확인 단계 | 확정 팝업 표시, 취소 시 확인 내용 유지 | 확정 대기 |
| 처음부터 다시 시작 | click | 완료 단계 | 입력·선택·오류·확인 문구·진행 상태 초기화 | 주제 선택 |

연습 목록의 검색·난이도 필터와 알림 폼은 별도 기능이므로 다시 시작해도 유지한다. 준비 흐름의 카드 강조와 선택 문구는 초기화한다.

## 교안 실습 반영 · 2026-10-14

7주차 교안 p.9–15의 연결 방식을 발표 연습 과업에 적용했다. 도서 교환의 책·교환 방식·장소는 발표 주제·연습 방식·함께 연습할 장소로 바꿨다.

- 진입 전 준비 영역은 `hidden`이다. 기존 연습 카드 또는 동의 후 활성화된 훈련 시작 버튼으로 진입한다.
- `showStep`은 `data-step`을 비교해 현재 화면만 보여 주고 진행 문구를 갱신한다.
- 청중과 함께 연습(`meet`)할 때만 장소를 표시하고 필수로 검사한다. 혼자 연습(`solo`)하면 장소·레이블을 숨기고 값·오류를 지운다.
- `showSummary`는 주제·난이도·목표·시간·연습 방식을 확인 화면에 반영한다.
- 완료 버튼은 `dialog.showModal()`을 실행한다. 다시 확인은 팝업만 닫고 값을 유지하며, 계획 확정은 팝업을 닫고 완료 화면으로 이동한다.
- 이전은 값을 유지한다. 다시 시작은 주제·입력·장소·오류·확인 문구를 지우고 연습 방식을 `meet`로 되돌린다. 설정·검색·알림 등 별도 기능은 유지한다.
- 6주차 테마·글자 수·동의·탭·검색·필터·알림 코드도 유지했다. `practice.js`와 `practice.css`는 week6 코드와 같다.

Chrome 1100·768·390px에서 진입 전 숨김, 주제·난이도·공백 목표 누락, 함께 연습의 장소 누락, 혼자 연습의 장소 숨김·초기화, 이전 값 유지, 10분→15분 수정 반영, 팝업 취소 값 유지, 확정 완료, 다시 시작 초기화를 확인했다. 가로 잘림과 검증 중 콘솔 오류가 없었다.
