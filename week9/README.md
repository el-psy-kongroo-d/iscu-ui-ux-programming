# 데브플랜 · 9주차: 입력 경험 및 저장 상태

개발 공부를 시작하는 학생과 초보 개발자가 오늘의 학습 주제, 학습 시간, 복습 문제 수를 정하고 계획을 다시 확인하는 정적 웹 프로토타입입니다.

- 학습 주제: 앞뒤 공백을 제거한 뒤 2~60자
- 학습 시간: 15분·30분·60분
- 복습: 선택 사항, 문제 수 1개·2개·3개
- 선택 입력: 학습자 이름
- 저장 범위: 이 브라우저의 `localStorage`. 저장 키는 `devplan-week9-plans-v1`이며 주차별로 분리됩니다. 같은 브라우저를 쓰는 동안 새로고침 후에도 저장한 계획을 읽습니다.

## 실행과 동작 검사

저장소 루트에서 다음을 실행합니다.

```sh
python3 -m http.server 8000
node --check week9/script.js
```

- 페이지: <http://localhost:8000/week9/>
- 브라우저 검사: <http://localhost:8000/week9/tests.html>

`tests.html`은 같은 출처에서 실제 페이지를 iframe으로 열어 이 주차의 주요 동작을 확인하는 수동 실행형 검사 페이지입니다. 검사 시작 시 기존 학습 계획 원문을 임시 보관하고, 성공·실패 또는 검사 페이지를 닫을 때 원래 값을 복원합니다. 브라우저 저장소에 접근할 수 없으면 검사를 시작하지 않습니다. LMS의 상세 과제 조건과 강의 영상을 직접 대조하지 않았으며, 브라우저에서 직접 실행한 결과는 아직 기록하지 않았습니다. 따라서 과제 완료·제출 가능·영상과 일치 여부를 단정하지 않습니다.

## 프로토타입 범위

계획은 기기 및 브라우저의 로컬 저장소에만 저장됩니다. 계정 간 동기화나 서버 저장은 없습니다. 실제 학습 진행을 측정하거나 복습 문제를 생성하지 않습니다. GitHub Pages 배포 상태는 확인하지 않았으며, 커밋·푸시 후 반영 여부 확인이 필요합니다.
